# Student Academic Risk Prediction System - Frontend

This is the frontend application for the **Student Academic Risk Prediction System**.

The frontend is built using:

- React
- TypeScript
- Vite
- Bootstrap
- Fetch API

The application allows users to manage student records and view Machine Learning predictions generated by the Python FastAPI backend.

---

## Project Features

The frontend supports:

- Add student data
- View all students
- Update student information
- Delete student records
- Click a student row to generate a prediction
- Display Machine Learning prediction results
- Display risk level
- Display class probabilities
- Display engineered academic features
- Communicate with the FastAPI backend
- Load student data from MySQL through the backend

---

## Prediction Classes

The Machine Learning model predicts one of the following academic outcomes:

- Dropout
- Enrolled
- Graduate

The application maps the prediction to a risk level:

| Prediction | Risk Level |
|---|---|
| Dropout | HIGH |
| Enrolled | MEDIUM |
| Graduate | LOW |

## Main Files

### `src/App.tsx`

The main application component.

Responsibilities:

- Load students from the backend
- Add students
- Delete students
- Update students
- Select students for prediction
- Open the edit modal
- Open the prediction modal

### `src/components/StudentForm.tsx`

Contains the student registration form.

The user enters:

- Student Name
- Age
- Gender
- Admission Grade
- Scholarship Holder
- Debtor Status
- Tuition Fees Up To Date
- Semester 1 Enrolled Units
- Semester 1 Approved Units
- Semester 1 Average Grade
- Semester 2 Enrolled Units
- Semester 2 Approved Units
- Semester 2 Average Grade

The frontend sends the student data to:

```text
POST /students
```

### `src/components/StudentList.tsx`

Displays all students saved in the database.

The list includes:

- Student ID
- Name
- Age
- Gender
- Admission Grade
- Semester 1 Grade
- Semester 2 Grade
- Edit button
- Delete button

Clicking a student row starts the Machine Learning prediction process.

### `src/components/EditStudentModal.tsx`

Allows the user to update existing student data.

The updated information is sent to:

```text
PUT /students/{student_id}
```

### `src/components/PredictionModal.tsx`

Displays the Machine Learning output.

The modal displays:

- Student Name
- Predicted Outcome
- Risk Level
- Prediction Probabilities
- Semester 1 Pass Rate
- Semester 2 Pass Rate
- Average Semester Grade
- Academic Progress
- Total Approved Units
- Financial Risk Score

### `src/services/studentApi.ts`

Contains API communication functions.

```text
GET     /students
POST    /students
PUT     /students/{student_id}
DELETE  /students/{student_id}
POST    /students/{student_id}/predict
```

The API base URL is:

```text
http://127.0.0.1:8000
```

Example:

```ts
const API_URL = "http://127.0.0.1:8000";
```

### `src/types/student.ts`

Contains TypeScript interfaces and types.

Main types:

- Gender
- Student
- StudentCreate
- PredictionResponse
- StudentSummary

Open a terminal inside the frontend directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

## Run the Frontend

Start the Vite development server:

```bash
npm run dev
```

The frontend normally runs at:

```text
http://localhost:5173
```

Create a production build:

```bash
npm run build
```

The production output will be generated inside:

```text

```

Preview the production build:

```bash
npm run preview
```

## API Endpoints Used by the Frontend


```json
  "admission_grade": 135,

  "semester1_approved_units": 5,
  "semester1_grade": 13.5,
  "semester2_enrolled_units": 6,
  "semester2_approved_units": 5,
  "semester2_grade": 14
}
```

### Update Student

```text
PUT /students/{student_id}
```

### Delete Student

```text
DELETE /students/{student_id}
```

### Predict Saved Student

```text
POST /students/{student_id}/predict
```

## Frontend Application Flow

```text
User opens application
        ↓
GET /students
        ↓
Load students from backend
        ↓
Display Student List
```

Add student:

```text
User enters student data
        ↓
StudentForm.tsx
        ↓
POST /students
        ↓
FastAPI
        ↓
MySQL
        ↓
Student saved
```

Update student:

```text
User clicks Edit
        ↓
EditStudentModal.tsx
        ↓
PUT /students/{id}
        ↓
FastAPI
        ↓
MySQL record updated
```

Delete student:

```text
User clicks Delete
        ↓
DELETE /students/{id}
        ↓
FastAPI
        ↓
Student removed from MySQL
```

Prediction:

```text
User clicks student row
        ↓
POST /students/{id}/predict
        ↓
FastAPI
        ↓
Student loaded from MySQL
        ↓
Machine Learning model
        ↓
Prediction response
        ↓
PredictionModal.tsx
```

---

## Important Notes

- Student records are not stored in localStorage.
- Student data is saved in the MySQL database through the backend.
- Prediction results come directly from the trained Machine Learning model.
- Prediction probabilities are not hard-coded in the frontend.
- The backend must be running for CRUD and prediction features to work.
